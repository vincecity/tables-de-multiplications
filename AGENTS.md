# AGENTS

## Project Scope
- Build and maintain a small web application to practice multiplication tables from 1 to 12.
- The app asks one random multiplication at a time, accepts a user answer, and gives immediate feedback (correct/incorrect with the right result).
- The app lets users select which tables (1 to 12) to include in the practice session.
- The app is installable from iOS home screen as a PWA (manifest, service worker, and local icons).
- The UI stays child-friendly (large question text and unicorn visual feedback for correct/incorrect answers).

## User Rules To Preserve
- Always keep this `AGENTS.md` file at the project root with the current project scope.
- On relevant changes, update this file if needed.
- For frontend work, default to using the `frontend-design` skill.
